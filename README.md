# 《勇者的召喚》(Call of Heroes) 數位桌遊系統

> 本研究以臺灣志願役士兵招募及訓練為靈感，將原創實體桌遊《勇者的召喚》完整數位化，提供「主辦方戰情大螢幕」、「參加方行動終端」、「單機同螢幕演練」以及「全能後台管理系統 (CMS)」。

---

## 🚀 快速啟動（只要有網址就能玩！）

### 方式 1：一鍵啟動（Windows 推薦）
雙擊執行專案目錄下的：
```bat
start.bat
```
系統會自動啟動並在瀏覽器中開啟：
- **本機遊玩網址**：`http://localhost:3000`
- **局域網連線網址（手機/平板掃碼或點擊進入）**：啟動終端會顯示當前區域網路 IP（例如 `http://192.168.x.x:3000`）

### 方式 2：指令列啟動
```bash
node server.js
```

## 🎯 系統架構與功能亮點

### 1. 🛡️ 主辦方戰情大螢幕模式 (`/#host`)
- **投影大螢幕適配**：大字體、作戰雷達儀表、4 位官兵軍籍資訊卡、動態戰情報導日誌。
- **作戰節奏掌控**：
  - 一鍵開啟「招募身分選擇」
  - 自動比對角色生日與玩家真實生日，計算最接近者作為先鋒順位
  - 即時監控全員訓練派遣與作戰擲骰狀態
  - 隨機抽取 20 張突發事件卡（含特效翻牌展示）
  - 發布 10 項實兵部隊任務令
  - 自動結算訓練素質成長（力量、靈敏、體力、智慧，保底最低 1 點）
  - 自動執行累功換章（3 嘉獎 = 1 小功、3 小功 = 1 大功、3 大功 = 一星寶星獎章）並裁定終局勝利者！
  - 支援裁判干預（微調數值、強制重置）。

### 2. 🎖️ 參加方行動終端 (`/#play`)
- **手機與平板極致優化**：直覺的大按鈕、滑動卡片與觸控介面。
- **身分選取**：
  - 高中畢業生（楊馨慧）：體力專長，精力充沛與團結力量
  - 大學畢業生（林星儀）：靈敏與綜合，專業學識與分析判斷
  - 社會人士（蔡嘉亨）：力量與領導，領導力與生存技巧
  - 專業人士（黃彥材）：智力與戰略，專業技能與戰略思維
- **動態迷彩軍籍圖板**：實時更新力量、靈敏、體力、智慧 4 項刻度與功獎徽章數量。
- **作戰骰子機**：逼真的戰術物理擲骰動效，命中面（國徽星芒）朝上自動結算。
- **協同作戰投骰**：團隊任務時可自由挑選最強素質投骰，共同累計團隊成功面數！

### 3. ⚔️ 單機同螢幕演練模式 (`/#solo`)
- 無需其他裝置或連線，一人即可分飾多角或示範教學，隨時隨地體驗完整回合流程！

### 4. ⚙️ 全能後台管理系統 (`/#admin`)
- **角色數據編輯**：自由修改 4 位角色的身分別、真實士兵名、生日、四項能力初始值、兩大專屬技能名稱與說明、背景特點與立繪圖片。
- **訓練模式編輯**：自由修改 7 種訓練名稱、內容介紹、通過門檻與屬性獎勵。
- **20 張事件庫編輯**：修改每張事件卡的情境文字、效果說明與數值邏輯。
- **10 張任務令編輯**：修改每張部隊任務的名稱、描述、通關條件與獎勵。
- **勳章折算與系統設置**：自訂嘉獎/小功/大功折算比例、訓練難度加倍週期、骰子判定命中門檻（預設 4+ 為命中面）、進階難度開關。
- **一鍵存檔與備份**：
  - 儲存後立即即時同步至所有連線中的房間！
  - 支援「匯出 JSON」與「匯入 JSON」檔案。
  - 支援「一鍵重設回桌遊原版配置」。

## 🎲 桌遊規則與數值核心

| 角色身分 | 代表士兵 | 生日 | 起始屬性 (力/敏/體/智) | 核心特長與技能 |
|---|---|---|---|---|
| **高中畢業生** | 楊馨慧 | 01-14 | 3 / 3 / 5 / 1 | 體力訓練 +1 骰；與隊友合訓各 +1 骰 |
| **大學畢業生** | 林星儀 | 08-15 | 1 / 5 / 2 / 4 | 獨自訓練 +1 骰；靈敏訓練 +1 骰 |
| **社會人士** | 蔡嘉亨 | 04-25 | 5 / 1 / 3 / 3 | 合訓時全員 +1 骰；力量訓練 +1 骰 |
| **專業人士** | 黃彥材 | 11-30 | 2 / 4 / 1 / 5 | 智力訓練 +1 骰；重複上回合訓練 +1 骰 |

- **訓練強度加倍**：每經過 5 個回合，因訓練強度增強，通過條件骰子數量加倍（x1 -> x2 -> x3...）。
- **勳章累積**：3 嘉獎 = 1 小功，3 小功 = 1 大功，3 大功 = 1 座一星寶星獎章。
- **勝利條件**：任一官兵取得一星寶星獎章時遊戲結束，由積存功獎最高者勝出！
